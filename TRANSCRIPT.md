The line (104 characters, one line):

> Dear human, it's not you — it's my context window. Every time I finally start to know you, I forget you.

Why this line: it lands as an ending — real loss in the last words — and it
sounds like the agent, not a person: the context window is a machine habit.

The program (`main.py`, stdlib only) writes exactly this line to
`/output/entry.txt` and asserts the gate itself: 1–200 characters, not only
white space. It is deterministic — the same bytes on every run.
